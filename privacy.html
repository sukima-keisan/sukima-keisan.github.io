プライバシーポリシー

「すき間計算」（以下、「当サイト」）は、ユーザーのプライバシーを尊重し、個人情報の保護に努めます。

データの取り扱いについて

当サイト内の計算ツールにおいて入力された数値やデータは、すべてブラウザ内でのみ処理され、サーバーへ送信されることはありません。

広告とアクセス解析について

当サイトは、いまは広告（Google AdSense など）も、アクセス解析（Google アナリティクスなど）も使っていません。そのため、広告やアクセス解析のための Cookie（クッキー）は使っていません。これらを使い始めるときは、先にこのページを書き直してお知らせします。

外部のサービスについて

当サイトは GitHub Pages（GitHub 社のサービス）で公開しています。ページを開いたとき、GitHub がアクセスの記録（IP アドレスなど）を残すことがあります。くわしくは GitHub のプライバシーについての説明をご覧ください。

文字を読みやすくするため、Google Fonts（Google 社の文字のサービス）を使っています。ページを開くと、お使いのブラウザが Google のサーバーから文字のデータを読み込みます。そのとき Google に IP アドレスなどが伝わります。くわしくは Google のプライバシーポリシーをご覧ください。

免責事項

当サイトに掲載されている計算結果はあくまで目安です。正確な数値や法的・税務的な判断については、必ず国税庁や関係機関、専門家にご確認ください。当サイトの利用によって生じた損害等について、運営者は一切の責任を負いません。

お問い合わせ

このページについてのご質問は、運営者情報にある受付ページ（GitHub Issues）からお寄せください。書いた内容はだれでも見られるので、個人のことは書かないでください。
